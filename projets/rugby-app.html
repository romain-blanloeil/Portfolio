Projet

App covoiturage rugby

Une application web en production, utilisée chaque semaine par les parents d'un groupe de jeunes pour organiser les trajets à l'entrainement de rugby et le planning goûter.

JavaScript Vercel Google Sheets API

Contexte

S'arranger pour du covoiturage est une bonne chose, mais organiser qui amène qui à l'entraînement et qui apporte le goûter chaque semaine se fait souvent à la main, par message. Cette application centralise les deux besoins dans un seul outil simple, pensé pour des parents qui n'ont pas de temps à perdre.

Note : les captures et la démo présentées ici sont anonymisées — prénoms fictifs, aucune donnée réelle des familles.

Stack technique

  • HTML / CSS / JavaScript vanilla — pas de framework
  • Déploiement sur Vercel
  • Backend léger : Google Sheets utilisé comme base de données via export CSV

Ce que ça fait concrètement

  • Gestion des trajets et des covoiturages pour les entraînements
  • Rotation automatique du goûter du lundi
  • Une fonction mondayIndex() qui saute correctement les périodes de vacances scolaires
  • Saisie des disponibilités via un formulaire Google existant, sans complexifier l'interface pour les parents

Défis & solutions

Éviter la complexité côté saisie. Plutôt que d'ajouter de la logique conditionnelle dans le formulaire Google (qui aurait décalé les colonnes du CSV export et cassé le parsing), le choix a été d'étendre le formulaire existant de façon simple — plus robuste à maintenir dans le temps qu'une branche conditionnelle fragile.

Ne pas se tromper de semaine. La fonction de rotation des trajets et du goûter devait ignorer les vacances scolaires pour ne pas décaler le planning réel — logique testée et ajustée jusqu'à un calcul fiable de l'index du lundi.

Résultat

Une application réellement utilisée chaque semaine par le groupe, en remplacement des échanges de messages pour organiser trajets et goûter.
